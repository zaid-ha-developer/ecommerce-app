## 📖 About The Project

**Zaid Online Store** is a fully responsive and modern e-commerce web application built with React and Vite.  
It offers a smooth shopping experience, allowing users to browse products, manage a shopping cart, and save their favorite items.

🔗 **Live Demo:** [https://ecommerce-app-8brn-8pbkb1rwi-zaid-fed4.vercel.app](https://ecommerce-app-8brn-8pbkb1rwi-zaid-fed4.vercel.app)

---

## ✨ Key Features

- 🛍️ **Product Browsing:** Browse through a wide range of products categorized for easy access.
- ❤️ **Favorites:** Add or remove products from a personal favorites list.
- 🛒 **Shopping Cart:** Add products to the cart, adjust quantities, or remove items easily.
- 🔍 **Live Search:** Search for products instantly with debounced input.
- 📦 **Product Details:** View detailed information and images for each product.
- 🎨 **Responsive Design:** Optimized and fully responsive across mobile, tablet, and desktop devices.
- 🌐 **Smooth Transitions:** Engaging page transitions powered by Framer Motion.
- 📞 **Contact & Blog:** Functional contact page with email and phone, and a dedicated blog section.

---

## 🛠️ Built With

- **React 18** – User Interface Library
- **Vite** – Next Generation Frontend Tooling
- **React Router DOM** – Declarative Routing
- **Context API** – Global State Management
- **Framer Motion** – Smooth Animations
- **React Hot Toast** – User-friendly Notifications
- **Swiper** – Interactive Sliders and Carousels
- **CSS3** – Custom Styling
